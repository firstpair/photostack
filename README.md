# The FirstPair Photo Stack

A short book that maps the FirstPair photo tools (tiffgraph, phidentify, phindex,
DNG Compare, Semantic Unison, packdir, Tursolite, diskproxy and Lightroom Repair),
how they fit together, and a walk through them end to end. Read it at
https://firstpair.org/books/photostack/.

`where-it-fits.md` is the block every photo book carries word for word;
`scripts/check-where-it-fits.py MANUSCRIPT...` checks a book's copy.
